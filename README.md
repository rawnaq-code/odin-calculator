# Calculator

A simple calculator built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/lessons/foundations-calculator).

## Live Demo

[View Live](https://rawnaq-code.github.io/odin-calculator/)

## GitHub Repository

[View Source Code](https://github.com/rawnaq-code/odin-calculator)

## Features

- Basic arithmetic operations
- Decimal number support
- Clear and delete buttons
- Keyboard support
- Minimal and responsive UI

## Built With

- HTML
- CSS
- JavaScript

- Switch Case usage (finally! my long lasting wish to use it in a project)
- Last but not the least how to combine concepts & use them to make a project
